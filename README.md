# 🐍👀 Snake Eyes - Red Dice Roller

Snake Eyes is a beautifully designed, highly interactive web-based dice rolling game built with **Node.js** and **Express**. It features two elegant, realistic red dice that roll with a satisfying 3D-like tumbling animation, calculates the sum of the dice instantly, and highlights special results like doubles or the legendary **Snake Eyes** (double ones)!

---

## ✨ Features

- **🔴 Sleek Red Dice**: Custom CSS Grid-based layout featuring a classic 3D-shaded crimson look with recessed white ivory dots aligned exactly like real dice.
- **🎲 Satisfying 3D Animation**: Realistic tumbling animations using smooth 3D-depth rotations coupled with high-frequency face shuffling during active rolls.
- **✨ Special Callouts**: Real-time feedback for standard rolls, doubles, and a special highlight for **Snake Eyes!**
- **💻 Multiple Ways to Roll**:
  - Click the **Roll Dice** button.
  - Click the **dice themselves** to toss them.
  - Press the <kbd>Spacebar</kbd> on your keyboard.
- **📱 Fully Responsive**: Optimized and looks fantastic on mobile, tablet, and desktop screens.

---

## 🛠️ Technology Stack

- **Backend**: Node.js, Express.js
- **Frontend**: Pure HTML5, CSS3 (Modern Flexbox/Grid, 3D Transforms, Keyframe Animations), and Vanilla JavaScript (ES6+).

## 🚀 Getting Started

Follow these simple instructions to install and run the game locally on your computer.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v14 or higher) installed on your machine.

### Installation

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/uberguru/snakeeyes.git
   cd snakeeyes
   ```

2. **Install the dependencies**:
   ```bash
   npm install
   ```

### Running the Application

1. **Start the local server**:
   ```bash
   node server.js
   ```

2. **Open the game in your browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) in your web browser.

---

## ⌨️ Controls

- **Click**: Click the "Roll Dice" button or the dice to roll them.
- **Spacebar**: Press <kbd>Space</kbd> to roll at any time.
